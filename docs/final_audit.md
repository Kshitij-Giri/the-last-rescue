## Remaining limitations of the study (unchanged; stated in report §12)

- **Non-convergence:** 5/350 runs are stable, and 0/40 main runs.
- **Sample size:** 10 seeds per condition.
- **A3:** the result is scale- and calibration-dependent.
- **A4:** confounded by distribution shift.
- **Greedy baseline:** moves in lockstep.
- **PSS:** tracks reward.
- **Critical level:** above its target band.
- **8 × 8 maps:** ρ is not comparable there.
- **Scope:** one environment, 3 agents, tabular IQL, no communication.

## ZIP integrity test

Procedure:
1. Build `the_last_rescue_final.zip`.
2. Run `unzip -t`.
3. Extract it into a fresh directory.
4. Check every file listed in `results/manifest.json` against its SHA-256.
5. Run the full test suite in the extracted copy.
6. Run `scripts/verify_results.py` in the extracted copy.

Results are recorded in `docs/zip_integrity.txt`, which is written after the test and therefore sits outside the hashed manifest.
